# 安卓自动点击器

无需 root、无需连电脑。用系统无障碍服务模拟点击/滑动，录制一次可重复运行。

## 编译安装
- Android Studio 打开本目录 → Run。
- 或推到 GitHub，仓库 Actions → Run workflow → 下载 app-debug。

## 手机配置（仅一次）
1. 开「悬浮窗权限」
2. 开「无障碍服务」里的本应用
3. 点「打开悬浮控制器」

## 使用
悬浮面板「录制」→ 屏幕点/滑 →「停录」→ 切到目标 App →「播放」。勾「循环」可反复。

## 注意
- 录的时候底层 App 不被操作，停录切 App 再播。
- 换横竖屏需重录。
- 金融/支付 App 可能拒绝运行，勿违规使用。
